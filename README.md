# ORACLE architecture

Interactive architecture diagram of ORACLE, a multi-agent investment desk. Seven agents debate a position over Telegram until they agree. Every number comes from a deterministic script, and the language model only writes the argument.

Open `index.html` in a browser. Hover to trace a flow, press R for routes, T for theme.

This is the architecture only. No code, keys, data or portfolio figures are included. Personal project, not financial advice.
